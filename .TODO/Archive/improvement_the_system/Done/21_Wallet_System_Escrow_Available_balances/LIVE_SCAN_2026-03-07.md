## 3) RPC: rpc_approve_delivery

- **Signature:** `(entity_type text, entity_id uuid)`.
- **Behavior:** SECURITY DEFINER; validates `auth.uid()` = client (task: owner_id; booking: client_id).
- **Branches:** `task`, `booking`. **No `direct_offer`** — else raises `Invalid entity type`.
- **Idempotency (booking):** Key = `encode(extensions.digest(entity_id || ':release_with_fee:' || v_status || ':' || v_payment_status, 'sha256'), 'hex')` — **deterministic, no `now()`.** Already applied (matches migration 20260307000001).
- **Decision:** direct_offer supported: **NO**. Migration required to add `direct_offer` branch.
